CASE-01

Daily web regression suite

PlaywrightPythonopenpyxlScheduler

Checking every page of tamashaweb.com by hand after each release took hours, and the same three subscription tiers had to be repeated each time. I automated the whole site check so it runs every morning and emails a colour-coded report to the team.

Coverage
38 modules per tier: navigation, browse filters, every category rail, each content-detail type (free and pro movies, programs, episodes, live), search, login, plans, profile and footer pages.
Tiers
Guest, AVOD and SVOD accounts, so access rules are checked for each type of user.
Output
A dated Excel report with pass, warning and fail rows, a detail CSV, and a run-history log with one row per run.
  • Shots like/unlike: taps the heart twice and confirms the icon and like count toggle, then revert.
  • Hero slider: confirms the Next arrow moves the slider, and that each slide opens its own content page.
  • Billing history: for subscribed users, downloads both PDF invoices and asserts a real file download.
CASE-02

Live TV channel health check

PlaywrightPythonHTML5 video

A live channel can look fine in the grid but be frozen or black once it plays. This script opens every free channel, watches it for 30 seconds, samples the player every 3 seconds, and classifies what it sees.

PLAYINGPlayback time advances steadily and the frame is not black.
FROZENPlayback time stops advancing, so the stream has stalled or is stuck buffering.
BLACKOUTThe player reports playing, but frame brightness is near zero.
NO STREAMNo video element, the player never becomes playable, or it shows an error.
  • Expands the full channel grid (90+ free channels plus Pro and Ad-Free variants) before testing.
  • Checks that every locked Pro or Ad-Free channel sends a guest to login instead of playing.
  • Writes a dated, colour-coded Excel report and a detail CSV for each run.
